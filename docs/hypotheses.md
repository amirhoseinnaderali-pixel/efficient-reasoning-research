# Hypotheses

- **H1:** Different allocations of a fixed inference-time budget may occupy different correctness/compute frontiers.
- **H2:** Deterministic execution should be the primary correctness signal for programming tasks.
- **H3:** Graph structure may improve candidate selection, but this is a hypothesis.
- **H4:** Refinement should be evaluated by marginal correctness versus the calls/tokens/latency it consumes.
